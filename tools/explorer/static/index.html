How this fits the teaching model

Choose an implementation directory, then select the catalog IDs its CLI supports. Its own loader resolves those IDs. The Worker registers Activities on the selected task list; Cadence routes the Workflow’s scheduled Activities to that Worker.

Inference belongs in Activities. Endpoints and credentials stay with the Worker. This explorer reads local files and previews commands; execute the copied commands in your terminal.
