## Methodology

The commit count includes commits reachable from the current `HEAD`. Source line
counts use the current working tree and include every nonblank line in `.py`,
`.go`, and `.sh` files. Comments and docstrings are included. Documentation,
configuration, generated metadata, virtual environments, and ignored files are
excluded.
